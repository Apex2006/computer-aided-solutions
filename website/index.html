Safety first

Anything that touches 230V waits for an expert.

Guides marked High risk do not go live right away. They wait in Expert Drafts until an expert approves them or sends them back to the author.

1

The author submits a high-risk guide

For example, a fan timer that switches mains power. It is saved as Pending, not published.

2

An expert reviews it

Experts see it in Expert Drafts, confirm the risk level and approve (Y) or return it (N). The first decision counts.

3

Readers see who checked it

Approved guides carry an "Approved by an expert" badge with the reviewer's name and date.

How someone becomes an expert

Experts are earned, not picked. Your guides need enough votes from every identity group, and the bar rises as more people use the app. Admins can also add experts directly, such as professors.

n = ⌈ N ÷ (1 + N × 0.05²) ⌉  Slovin's formula, 5% margin of error

The n votes are split across Students, Professionals, Hobbyists and Educators in proportion to each group's size. Admin-added experts show Admin approved instead of a rate.

Install

Up and running in about a minute.

Everything the app needs is inside the installer, so the PC does not need Java, NetBeans or an administrator password.

  1. Download the installer

    You get one file, Computer-Aided Solutions Setup.exe. If your browser says it is not commonly downloaded, choose Keep.

    Download for Windows

    Download not starting? Open it in Google Drive and click the download icon.

  2. Open it

    Double-click the file. If a blue "Windows protected your PC" box appears, click More info and then Run anyway. Windows shows this for new apps that are not signed by a big company.

  3. Next, Install, Finish

    The app opens at the login screen. After that, open it from the green icon on your Desktop or in the Start menu.

Questions

Before you ask.

Why does Windows warn me before it opens?

Windows SmartScreen warns about any new app that has not been signed with a paid certificate. Click More info, then Run anyway. You only see it once.

Do I need an account?

You can click Continue as Guest to read every published guide. Create a free account to vote, comment, report problems and write your own guides.

Is this a website?

No. It is a desktop app built with JavaFX. This page only introduces it and hands out the installer. The guides live in a cloud database, so everyone sees the same library from any PC.

Does it work on a Mac or a phone?

Not yet. This version is for Windows 10 and 11 only.

How do I update to a newer version?

Download the new installer and run it. It replaces the old version and keeps your shortcuts. Your account and guides are in the cloud, so nothing is lost.

How do I uninstall it?

Open Settings, then Apps, then Installed apps. Find Computer-Aided Solutions and click Uninstall. Your account stays in the cloud if you install it again later.
